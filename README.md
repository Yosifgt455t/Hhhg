# تطبيق فلاتر التجريبي (Flutter Demo App) 📱

تطبيق فلاتر أنيق وعصري مصمم بأحدث معايير **Material 3** ومهيأ بالكامل للبناء التلقائي واستخراج ملف **APK** جاهز للتثبيت عبر **GitHub Actions**.

---

## 🚀 طريقة بناء وتصدير ملف الـ APK عبر GitHub

### الخطوة 1: إنشاء مستودع جديد على GitHub
1. افتح موقع [GitHub](https://github.com) وأنشئ مستودعاً جديداً (New Repository) فارغاً باسم (مثلاً: `flutter-demo-app`).
2. اختر أن يكون المستودع عاماً (Public) أو خاصاً (Private).

### الخطوة 2: ربط المشروع ورفع الكود من Termux
شغّل الأوامر التالية بالترتيب داخل مجلد المشروع:

```bash
# 1. تهيئة مستودع Git محلي
git init

# 2. تحديد الفرع الرئيسي
git branch -M main

# 3. إضافة وتثبيت الملفات
git add .
git commit -m "feat: initial flutter app with apk build workflow"

# 4. ربط المستودع البعيد (استبدل USERNAME و REPO باسم حسابك ومستودعك)
git remote add origin https://github.com/USERNAME/REPO.git

# 5. رفع الكود
git push -u origin main
```

---

## ⚡ الخطوة 3: مراقبة البناء وتحميل الـ APK

1. افتح صفحة مستودعك على موقع **GitHub** من متصفح الهاتف أو الكمبيوتر.
2. توجه إلى تبويب **Actions** في الأعلى.
3. ستجد سير العمل بعنوان **`Build & Export Flutter APK`** يعمل تلقائياً (تظهر علامة صفراء تدور).
4. يستغرق البناء عادةً من 2 إلى 3 دقائق على خوادم GitHub.
5. بمجرد اكتمال البناء وظهور علامة الصح الخضراء ✅:
   - اضغط على اسم الـ Run (مثلاً: `feat: initial flutter app...`).
   - انزل لأسفل الصفحة إلى قسم **Artifacts**.
   - ستجد ملفاً باسم **`FlutterDemoApp-v1.0.0-APK`**.
   - اضغط عليه لتحميله، ثم فك الضغط (إن تم تنزيله كـ zip) وثبّت ملف الـ `.apk` على هاتفك فوراً!

* **Flutter SDK**: 3.x
* **Dart**: 3.x
* **UI**: Material 3 Design
* **الدعم**: دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL)
* **الميزات**:
  * تبديل سلس بين الوضع الليلي والنهاري (Dark / Light Theme).

  * شاشة عرض مميزات وتنبيهات SnackBar.
  * هيكل جاهز للتوسيع لأي فكرة تطبيق أخرى.
